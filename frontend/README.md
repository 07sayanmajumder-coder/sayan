# Where is my Train — modular React demo

## Setup
1. Install Node.js.
2. Open this project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Pages
- `/` Home
- `/about` About
- `/contact` Contact
- `/login` Sign In
- `/signup` Sign Up
- `/book-ticket` Booking (requires demo sign-in)

## Important
Authentication is a frontend-only demonstration using localStorage. Do not use it for real accounts: passwords are stored in the browser and there is no secure backend. Train information, seat counts, payment, and PNR are also simulated. A production railway booking system needs a secure backend, verified railway data, real authentication, and a payment provider.
